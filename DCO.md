# Developer Certificate of Origin

This project uses the Developer Certificate of Origin 1.1 for contributions.

The canonical DCO text is maintained at <https://developercertificate.org/>.

By adding a `Signed-off-by` trailer to a commit, the contributor certifies that the contribution can
be submitted under this repository's open source licence terms and that the public contribution
record, including the sign-off identity, may be maintained indefinitely.

Example trailer:

```text
Signed-off-by: Jane Contributor <jane@example.com>
```

Use `git commit -s` to add the trailer automatically.
