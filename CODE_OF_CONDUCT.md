# Code of Conduct

This project expects respectful, constructive collaboration.

## Expected Behaviour

- Be considerate and direct.
- Focus criticism on code, design, evidence, and safety impact.
- Assume good intent while still taking security concerns seriously.
- Respect maintainers' decisions about scope, risk, and release timing.

## Unacceptable Behaviour

- Harassment, threats, or discriminatory language.
- Publishing private security reports before maintainers have had a reasonable chance to respond.
- Sharing real secrets, credentials, private keys, or personal data in issues, discussions, or test
  cases.

## Enforcement

Maintainers may remove comments, close issues, block participants, or decline contributions that
make the project unsafe or hostile.

For urgent platform abuse, use GitHub's abuse reporting tools. For project-specific conduct concerns,
contact the maintainer privately when a private channel is already available; otherwise open the
smallest public issue that can describe the concern without exposing private people, repositories,
secrets, or security details.
